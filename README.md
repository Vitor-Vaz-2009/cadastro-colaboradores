# Cadastro de Colaboradores

Sistema simples de cadastro de colaboradores desenvolvido como atividade escolar utilizando HTML, PHP e CSS.

## Sobre o projeto

O projeto possui um formulário para cadastrar informações de novos colaboradores da empresa.

O formulário solicita:

* Nome completo
* Idade
* Profissão
* Salário pretendido
* Experiência anterior

Após o envio, os dados são recebidos pelo PHP através do método `POST` e apresentados em uma página de confirmação.

## Arquivos

* `cadastro.html` — formulário de cadastro.
* `processaCadastro.php` — recebe e apresenta os dados enviados.
* `estilo.css` — estilização básica do formulário.

## Como executar

O projeto foi desenvolvido utilizando o XAMPP.

Para executar:

1. Coloque os arquivos na pasta `htdocs` do XAMPP.
2. Inicie o servidor Apache.
3. Abra o navegador.
4. Acesse `http://localhost/cadastro.html`.

## Tecnologias utilizadas

* HTML
* PHP
* CSS
* XAMPP / Apache
